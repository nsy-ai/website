# nsyAI — Site vitrine

Site vitrine de l'agence d'intelligence artificielle **nsyAI**. Site statique (HTML/CSS/JS, sans framework) — rapide, accessible et hébergeable partout (GitHub Pages, Netlify, Vercel…).

## Structure

- `index.html` — page unique : hero, services, méthode, réalisations, agence, contact
- `styles.css` — design system et styles
- `script.js` — menu mobile, terminal animé, validation du formulaire, header sticky
- `favicon.svg` — logo

## Développement

Aucun build requis. Ouvrir `index.html` dans un navigateur, ou :

```bash
npx serve .
```

## Déploiement

Pousser sur `main` suffit si GitHub Pages est activé sur ce dépôt (branche `main`, racine `/`).
